# خدمات بيانات ERP الأساسية

## الملف البرمجي
`lib/erp/services/erp_master_data_service.dart`

الخدمة توفر عمليات قراءة وإضافة وتعديل بيانات:
- الفروع `erp_branches`
- فئات الأصناف `erp_item_categories`، ويرتبط الصنف بالفئة من خلال `erp_items.category_id`
- الأصناف `erp_items`
- الموردين والعملاء والأطراف المشتركة `erp_parties`

## طريقة الربط من الشاشة
أنشئ `ErpMasterDataService()` داخل طبقة المستودع أو الشاشة التي تحتاج البيانات، ثم استدعِ الوظائف بتمرير معرّف الشركة الذي جرى التحقق من صلاحية المستخدم عليه. لا تستنتج معرّف الشركة من مدخل نصي غير موثوق ولا تسمح للعميل باختيار شركة أخرى دون تحقق.

## قبل التشغيل
- يجب تطبيق `supabase/erp_schema.sql` على قاعدة البيانات المستهدفة بعد مراجعة الجداول الموجودة لتجنب التعارض.
- مخطط الأساس يفعّل RLS دون سياسات سماح عامة؛ أضف سياسات مقيدة بالشركة/المستخدم وفق نموذج العضوية الفعلي قبل استخدام هذه الخدمة.
- لا تستخدم `service_role` داخل تطبيق Flutter أو الويب.
- هذه الخدمة لا تحذف سجلات ولا تنشئ شركة أو عضوية تلقائيًا.
- لم يتم تشغيل اختبارات أو بناء، ولم يتم الاتصال بقاعدة Supabase أو تعديل بيانات حية.

## الحقول الأساسية
### الأصناف
كود الصنف، الاسم، الفئة، الباركود، وحدة القياس، سعر الشراء، سعر البيع، حد إعادة الطلب، تتبع الصلاحية، وحالة النشاط.

### الموردون والعملاء
الكود، الاسم، النوع (`supplier` أو `customer` أو `both`)، الهاتف وواتساب والبريد والعنوان والمحافظة والمنطقة وحد الائتمان والرصيد الافتتاحي وحالة النشاط.

### الفروع وفئات الأصناف
لكل فئة كود واسم وحالة نشاط، ويمكن ربط الفئة بفئة أب ضمن شجرة الفئات.
