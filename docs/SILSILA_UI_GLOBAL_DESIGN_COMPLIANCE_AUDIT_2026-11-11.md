# تدقيق معايير الواجهات العامة في Flutter — سلسلة ERP
التاريخ: 2026-11-11
المصادر: `lib/main.dart`, `lib/core/app_theme.dart`, `erp_quick_task_button.dart` وعينات من شاشات ERP.

## 1. النتيجة
يوجد ملف Theme مستقل يحقق جزءًا كبيرًا من معيار 40px/5px، لكنه **غير مستخدم** في `main.dart`. التطبيق يعمل حاليًا بـThemeData inline داخل `SilsilaApp`.

## 2. مقارنة القيم الفعلية

| العنصر | المعيار المعتمد للمشروع | Theme النشط في main.dart | Theme غير المستخدم في app_theme.dart |
|---|---:|---:|---:|
| ارتفاع حقل الإدخال | 40px ثابت | min 40 / max 44 | min 40 / max 40 |
| ارتفاع صف DataTable | 40px | min 48 / max 64 | min 40 / max 40 |
| ارتفاع رأس الجدول | 40px | 48px | 40px |
| المسافة بين الأعمدة | 5px | 14px | 5px |
| الهامش الأفقي للجدول | 5px | 12px | 5px |
| ارتفاع خيار Dropdown | 40px | لا توجد قاعدة عامة | لا توجد قاعدة عامة |
| موضع عنوان الحقل | بجوار الحقل | `InputDecoration.labelText` الافتراضي؛ لا يفرض عنوانًا جانبيًا | لا يفرض عنوانًا جانبيًا |
| Checkbox | دائري | دائري | دائري |
| الخط الرئيسي | Tajawal | Tajawal | Tajawal |
| ألوان الهوية | بنفسجي/برتقالي/وردي | موجودة | موجودة |

## 3. نتائج مؤكدة
1. `main.dart` لا يستورد `SilsilaTheme` ولا يستخدم `SilsilaTheme.light`.
2. `main.dart` يحدد DataTable rows 48–64 وheading 48 وspacing 14؛ وهذا يخالف معيار 40/5.
3. حقل الإدخال في Theme النشط يقبل ارتفاعًا يصل إلى 44، وليس 40 ثابتًا.
4. لا توجد قاعدة عامة لـDropdown itemHeight في Theme النشط؛ بعض الشاشات تحدد `itemHeight:40` محليًا فقط.
5. لا توجد أداة موحدة لعرض label بجانب input؛ كثير من الشاشات تستخدم `InputDecoration.labelText`.
6. `ErpQuickTaskButton` يطابق ألوان أزرار تحديث/إضافة/حفظ/تعديل/حذف/معاينة/Excel/PDF، لكنه لا يفرض ارتفاعًا ثابتًا 40px، ويضيف padding عموديًا 10 أو 8 حسب compact.
7. ملف `app_theme.dart` يحقق 40px للحقول والصفوف و5px للجدول، لكنه ليس المصدر النشط؛ وجوده وحده لا يعني أن المعيار مطبق.

## 4. عقد التصميم الموحد المطلوب
### 4.1 مصدر Theme واحد
- جعل Theme واحدًا هو المصدر النهائي في `SilsilaApp`; إزالة التكرار بين `main.dart` و`app_theme.dart` بعد دمج كل خصائص الهوية والسلوك المطلوبة.
- InputDecoration constraints: 40px ثابتة دون max 44.
- DataTable heading/data row: 40px ثابتة؛ horizontalMargin 5 وcolumnSpacing 5.
- Dropdown/Popup menu: 48px minimum interactive tap target (Flutter constraint); field controls remain 40px.
- الحفاظ على checkbox الدائري، Tajawal، ألوان الهوية، RTL، التباين، وأحجام الأزرار المعتمدة.

### 4.2 مكون حقل موحد
- إنشاء مكون مثل `ErpLabeledField`: label مستقل بجوار الحقل، RTL-aware، عرض label مضبوط، input height40، validation/error داخل الصف دون زيادة الارتفاع الطبيعي قدر الإمكان.
- دعم text/number/date/search/dropdown/checkbox/radio من عقد واحد.
- لا تضع `labelText` داخل InputDecoration إذا كان معيار الشاشة يطلب عنوانًا جانبيًا؛ استخدم label منفصلًا.
- كل اختيار داخل Dropdown 40px؛ لا تترك كل شاشة تختار itemHeight من نفسها.

### 4.3 الجداول والصفحات
- صفوف grid الأساسية 40px، spacing 5px.
- لا تسمح لـDataTable الافتراضي بإرجاع ارتفاع 48–64 في شاشات ERP.
- أي شاشة تحتاج كثافة مختلفة توثق الاستثناء صراحة، ولا تغير المعيار العام.
- الحفاظ على scroll behavior دون إدخال scroll أفقي بين الصفوف أو تغيير تجربة العرض المعتمدة.
- الموبايل: لا تكسر حروف شعار سلسلة، لا تكبر الهيدر، واحتفظ بأزرار الإجراءات قابلة للوصول.

### 4.4 أزرار المهام
- المجموعة القياسية تسعة أزرار: تحديث، إضافة، حفظ، تعديل، حذف، معاينة، طباعة، Excel، PDF.
- ألوان/أيقونات ErpQuickTaskButton الحالية أساس صالح؛ يضاف قياس ثابت وتوحيد spacing دون تغيير ألوان المعنى.
- لا تعرض زرًا بلا callback فعال؛ ولا تظهر نجاحًا قبل اكتمال العملية.

## 5. قرار قبل إغلاق التصميم
- لا تعتبر الهوية البصرية مكتملة 100% قبل توحيد Theme النشط مع المعايير، وإضافة مكون label الجانبي، وضمان ارتفاع القوائم.
- لا يتم تعديل الكود في هذه المرحلة؛ ينفذ توحيد Theme ومكونات الحقول مرة واحدة ضمن دفعة التصميم/الربط المعتمدة، ثم يختبر مرة واحدة في النهاية.
