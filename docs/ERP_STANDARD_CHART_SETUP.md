# إعداد شجرة الحسابات القياسية — سلسلة ERP

## ما الذي يفعله الملف؟
الملف `supabase/erp_seed_standard_chart_of_accounts.sql` يعرّف دالة تضيف شجرة حسابات عربية قياسية مناسبة لنشاط تجارة وتوزيع المواد الغذائية بالجملة، تحت الشركة التي تحددها. يشمل الأصول، الالتزامات، حقوق الملكية، الإيرادات، وتكلفة النشاط والمصروفات.

الدالة قابلة لإعادة التشغيل: لا تكرر أكواد الحسابات الموجودة للشركة، ولا تعدّل الحسابات الموجودة بالفعل. وهي تعيد عدد الحسابات الجديدة التي أضافتها.

## التطبيق على قاعدة Supabase الفعلية

1. افتح مشروع Supabase الصحيح ثم **SQL Editor**.
2. افتح ملف `supabase/erp_seed_standard_chart_of_accounts.sql` في المستودع وانسخ محتواه كاملًا إلى استعلام جديد في SQL Editor، ثم اضغط **Run**. هذه الخطوة تنشئ الدالة فقط؛ لا تختار شركة تلقائيًا ولا تضيف الحسابات بعد.
3. اعرض الشركات المسجلة لتحديد الشركة المقصودة:
   ```sql
   select id, legal_name, trade_name
   from public.erp_companies
   order by created_at;
   ```
4. انسخ معرّف `id` للشركة الصحيحة، ثم شغّل:
   ```sql
   select public.erp_seed_standard_chart_of_accounts('ضع-معرّف-الشركة-هنا'::uuid);
   ```
   استبدل النص داخل علامات الاقتباس بمعرّف UUID الحقيقي. النتيجة رقم الحسابات الجديدة التي تمت إضافتها.
5. للتحقق:
   ```sql
   select account_code, account_name, account_type, normal_balance,
          parent_id, is_postable, is_active
   from public.erp_accounts
   where company_id = 'ضع-معرّف-الشركة-هنا'::uuid
   order by account_code;
   ```

## تنبيهات مهمة
- يجب أن تكون جداول `erp_companies` و`erp_accounts` موجودة أولًا؛ طبّق `supabase/erp_schema.sql` قبل ملف البذر إذا لم يكن المخطط مطبقًا.
- يفضّل تطبيق `supabase/erp_account_integrity.sql` أيضًا حتى تتحقق قاعدة البيانات من صحة العلاقات الهرمية.
- شغّل الاستعلامات في مشروع Supabase الصحيح وبصلاحية إدارية موثوقة. لا تضع مفتاح `service_role` داخل التطبيق أو المستودع.
- إذا لم تظهر أي شركة، أنشئ/أكمل سجل الشركة من شاشة بيانات الشركة أولًا؛ لا تستخدم معرّفًا تخمينيًا.
- هذه شجرة تأسيسية عامة وليست بديلًا عن مراجعة محاسب مصري لتخصيص الضرائب والحسابات وفق طبيعة الشركة ومعالجتها الضريبية الفعلية.
