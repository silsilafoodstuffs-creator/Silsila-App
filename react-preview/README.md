# سلسلة — React ERP Preview

نسخة React مستقلة لتطوير واختبار واجهات سلسلة ووظائفها تدريجيًا، بالتوازي مع تطبيق Flutter الحالي. لا يتم حذف تطبيق Flutter أو استبداله قبل اكتمال التحقق والاعتماد.

## ما هو متصل حاليًا

- المصادقة عبر Supabase Auth بالبريد الإلكتروني وكلمة المرور.
- تحميل عضويات المنشآت النشطة من `erp_company_members` وبيانات المنشآت من `erp_companies`.
- نطاق المنشأة المختارة محفوظ في جلسة المتصفح، وتُقرأ البيانات التشغيلية من Supabase وفق سياسات RLS.
- لوحة تنفيذية وواجهات مستندات وخزينة وقيود مرتبطة بقاعدة البيانات في الشاشات التي تحمل توضيح الاتصال.
- وضع المعاينة لا ينشئ مستندات ولا يكتب بيانات في قاعدة الإنتاج.

> تنبيه: بعض الشاشات ما زالت عرضًا أو CRUD محليًا، وبعض دورات العمل تحتاج استكمالًا. نجاح البناء لا يعني أن كل إجراء تشغيلي تم اختباره على قاعدة فعلية.

## التشغيل المحلي

```bash
cd react-preview
npm install
npm run dev
```

## الاختبارات

```bash
npm run build
npx playwright install chromium
npm run test:e2e
```

اختبارات المتصفح تتحقق من شاشة الدخول، الدخول إلى المعاينة، ظهور التنقل الأساسي، وأساسيات العرض على الهاتف. لا تستخدم بيانات اعتماد حقيقية داخل اختبارات CI ولا تنشئ معاملات في قاعدة الإنتاج.

## بيئات التشغيل

- وجهة النشر المعتمدة: مستودع GitHub مستقل باسم Silsila-React، مع GitHub Pages كرابط تشغيل ثابت. لم يُنشأ المستودع المستقل أو يُفعّل Pages بعد؛ لذلك لا يوجد رابط React رسمي منشور حتى الآن.
- يُلغى الاعتماد على Vercel نهائيًا، ولا تُستخدم روابط Preview المؤقتة كرابط تشغيل.
- بعد فصل المستودع، تُضبط VITE_SUPABASE_URL وVITE_SUPABASE_PUBLISHABLE_KEY كإعدادات بناء آمنة في GitHub Actions. لا يوضع أي Service Role Key أو سر إداري داخل تطبيق الواجهة.
- لا تُنفّذ تغييرات على مخطط قاعدة الإنتاج أو بياناتها دون خطة وموافقة صريحة.


## محرر التعديل الموحد

- لوحة RTL جانبية من اليسار فوق الشاشة الأصلية، مستخدمة حاليًا في الأصناف والسياسات والعملاء والموردين والبيانات الأساسية والمخازن والخزائن والحسابات وقيود اليومية.
- التغييرات غير المحفوظة تُحرس عند الإغلاق أو النقر خارج اللوحة أو التنقل في القائمة أو الخروج من البرنامج، مع تأكيد نعم/لا/إلغاء.
- زر الحفظ داخل اللوحة يستخدم نفس دورة الحفظ المركزية؛ لا تغلق اللوحة عند فشل الحفظ، وتظل التغييرات متاحة للمراجعة أو إعادة المحاولة.
- تحديث المتصفح/إغلاق التبويب مع تغييرات غير محفوظة يعرض تحذير المتصفح.
- ما زالت هناك شاشات لم يُنقل نموذجها إلى اللوحة أو لا تدعم تعديل المستند بعد إنشائه؛ لا تعتبر هذا المكوّن مطبقًا على جميع تدفقات ERP حتى إغلاق الجرد.
